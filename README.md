# Warning_trashcan
Its an addition to trashcans that sends an email when the trashcan is full, this is made using an esp-32, 2 ultrasonic sensors, and... cardboard for the body of the build... This proyect was programed in VScode using the PlataformIO plugin, this was designed to be able to cennect to intyernet and send emails, the loop or logic that i used in the code was to first connect to WiFi, and then it starts reading the sensors, if something is detected within 20cm from the sensor we wait another 5 seconds, and after these 5 seconds the esp32 reads the sensors again, if the object is still there we send the email, this is done to prevent the esp32 from detecting something that just passed by.
